# UniStation

[English](README.md) · [Сайт](https://ustation.ru/)

Я делаю UniStation с помощью нейросетей для собственной работы и делюсь им
с теми, кому это интересно. Проект ориентирован на пользователей MicroStation
и AutoCAD. Пока это экспериментальный верстак FreeCAD; в дальнейшем возможен
форк FreeCAD. Точный ввод обеспечивает AxisFlow — аналог AccuDraw.

**[Скачать Windows-инсталлятор v0.1.0-alpha.12](https://github.com/LeonidWiebe/UniStation/releases/download/v0.1.0-alpha.12/UniStation-0.1.0-alpha.12-win64-setup.exe)** ·
[Описание выпуска](docs/release-v0.1.0-alpha.12.md).

Выберите UniStation/AxisFlow, FreeCAD, документацию/ярлыки и родительский Mod.
По умолчанию `%APPDATA%\FreeCAD\v1-1\Mod`. FreeCAD устанавливается отдельно.
Ярлык **UniStation - FreeCAD** открывает его с активным верстаком.
[Инструкция](docs/installer.md).

## Возможности

- Построение и редактирование поддерживаемых целых объектов с AxisFlow и привязками Draft.
- Продолжение Line включено при запуске: конец отрезка задаёт начало следующего.
- Прямые и точные круговые сегменты Wire в одном объекте.
- Слои FCStd, немодальный менеджер, назначение, Global Display/Freeze,
  Lock поддерживаемых операций, Plot, «По слою» и Change Attributes.
- Edit Palette: 256 индексных цветов, Load/Save JSON; прямой PDF для геометрии XY.
- Пять панелей, русский/английский интерфейс, окно координат и живые атрибуты.
- Новые значки FreeCAD/Windows и исправление восстановления автоширины панелей.

[Работа](docs/usage.md) · [Состояние и ограничения](docs/status.md).
Rectangle/Freeform и Scale/Rotate/Mirror/Array остаются заготовками.
Move/Copy требуют предварительного выбора поддерживаемых целых объектов.
Показ слоёв по видам, защита вне UniStation, внешние библиотеки и TechDraw отложены.

## Проверки

Windows x64 / Python 3.11, FreeCAD 1.1.1–1.1.4. Прежние версии проверялись
в 1.1.1 и 1.1.3; новые функции — в 1.1.4. Полная проверка alpha.12 во всём
диапазоне и произвольный ABI не подтверждены.

Line: 22/22 целевых Python-тестов и 2/2 Qt-сценариев; Wire: 14/14 и 1/1.
Ручные пробы обеих функций приняты в своём объёме. Проверка установщика
alpha.11 принята; отдельная проба нового EXE alpha.12 и установленных функций
ещё ожидается. Для публикации новые тесты и GUI не запускались. EXE не подписан.
[Подробности](docs/testing.md).

При полном удалении оба компонента отмечены по умолчанию, а копии после удаления
последнего компонента автоматически отправляются в Корзину. Ошибки очистки
сохраняют сообщение с путём. [Удаление](docs/installer.md#upgrade-and-removal).
