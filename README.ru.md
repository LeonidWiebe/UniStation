# UniStation

[English](README.md)

UniStation — экспериментальный Python Workbench для FreeCAD с приёмами
черчения, знакомыми по MicroStation. Основной ввод точек обеспечивает
[AxisFlow](https://github.com/LeonidWiebe/AxisFlow).

Это исходный снимок работающего прототипа. Документированная локальная среда —
Windows и FreeCAD 1.1.4. Установочный комплект, проверенный на отдельном
компьютере, ещё готовится. FreeCAD и бинарник AxisFlow в репозиторий не входят.
В отдельной ветке подготовлен [кандидат пакета](docs/distribution.md):
[установка](packaging/INSTALL.md), [короткая пользовательская проба](packaging/USER-CHECK.md).
GitHub Release ещё не создан; новая установка ожидает проверки.

## Что доступно

- Отрезок, открытая/замкнутая ломаная, окружность по центру и точке радиуса,
  дуга через три точки.
- Move и Copy для поддерживаемых, предварительно выделенных целых объектов.
- Палитра документа: 256 индексных цветов, импорт/экспорт JSON.
- Активные цвет, четыре стиля линии и 32 индекса экранной толщины для новых
  элементов. Их можно менять во время рисования без потери принятых точек.
- Шесть панелей, общие привязки Draft/AxisFlow, назначение ПКМ Reset,
  автовыделение результата по настройке, русский и английский интерфейсы.
- Отдельное немодальное окно координат для Line/Wire/Circle: мировые XYZ,
  `abs`/`rel`, единицы mm/cm/m.

Команды учитывают текущее состояние компаса AxisFlow. Circle следует текущей
ориентации. Arc сохраняет принятые мировые точки и определяет итоговую
плоскость тремя точками дуги.

Слой, Прямоугольник, Произвольная форма, Масштаб, Поворот, Зеркало и Массив —
отключённые заготовки. Слои и режим «По слою» не реализованы.
[Текущий статус и ограничения](docs/status.md).

## С чего начать

1. Прочитайте [описание зависимостей](docs/dependencies.md) и
   [порядок ручной установки](docs/installation.md).
2. Используйте [руководство](docs/usage.md) в совместимой среде FreeCAD/AxisFlow.
3. Учитывайте [состояние проверок](docs/testing.md): сохранённые тесты
   не означают, что этот опубликованный снимок прошёл новый прогон.

Ручная установка описана для опытного пользователя FreeCAD; на чистом
компьютере она пока отдельно не подтверждена. Установки через Addon Manager,
portable-комплекта и готового установщика здесь пока нет.
