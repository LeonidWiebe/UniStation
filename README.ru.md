# UniStation

[English](README.md) · [Сайт](https://ustation.ru/)

Я делаю UniStation с помощью нейросетей для собственной работы и делюсь им
с теми, кому это интересно. Проект ориентирован на пользователей MicroStation
и AutoCAD. Пока это экспериментальный верстак FreeCAD; в дальнейшем возможен
форк FreeCAD. Точный ввод обеспечивает AxisFlow — аналог AccuDraw.

**[Скачать Windows-инсталлятор v0.1.0-alpha.6](https://github.com/LeonidWiebe/UniStation/releases/download/v0.1.0-alpha.6/UniStation-0.1.0-alpha.6-win64-setup.exe)** ·
[Описание выпуска](docs/release-v0.1.0-alpha.6.md).

Мастер находит FreeCAD или предлагает указать EXE, проверяет версию и
устанавливает выбранные UniStation/AxisFlow для текущего пользователя Windows.
По умолчанию `%APPDATA%\FreeCAD\v1-1\Mod`. Ярлык **«UniStation - FreeCAD»**
открывает выбранный FreeCAD с активным UniStation. FreeCAD устанавливается отдельно.
[Инструкция](docs/installer.md).

## Возможности

- Построение и редактирование поддерживаемых целых объектов с AxisFlow,
  динамическими атрибутами и общими привязками Draft.
- Слои FCStd: немодальный менеджер, назначение/активный слой, Global Display,
  Global Freeze, Lock в поддерживаемых операциях и Plot.
- Сохраняемые цвет/стиль/толщина «По слою» и Change Attributes.
- Edit Palette: 256 индексных цветов, Load/Save JSON.
- Прямой векторный PDF для планарной геометрии XY, форматы A4–A0 и масштаб.
- Пять панелей, русский/английский интерфейс и отдельное окно координат.

[Работа](docs/usage.md) · [Состояние и ограничения](docs/status.md).
Rectangle/Freeform и Scale/Rotate/Mirror/Array остаются заготовками.
Move/Copy работают с предварительно выделенными поддерживаемыми целыми объектами.
Показ слоёв по видам, защита вне UniStation, внешние библиотеки и TechDraw отложены.

## Проверки

Windows x64 / Python 3.11, заявленный диапазон FreeCAD 1.1.1–1.1.4.
Прежняя версия проверена в 1.1.1; новые функции проверялись в 1.1.4.
Полная регрессия alpha.6 в 1.1.1 и произвольный ABI не подтверждены.

Unit-прогон alpha.4: **58 из 67 успешно, 5 неуспешных проверок и 4 ошибки**
в прежних тестах Circle/Arc; ограничение тестовых объектов сохраняется.
Ручные установка и запуск FreeCAD прошли успешно; повтор удаления после
исправления alpha.6 успешен в объёме этой пробы. Полная регрессия, все ветки
обнаружения и аварийный откат не подтверждены. Новых автопрогонов нет.
EXE не подписан.
[Подробности](docs/testing.md).

## Планы

Локальная конфигурация проекта и пути поиска, затем внешние библиотеки слоёв;
библиотеки блоков (cell/shared cell), отдельный менеджер references и saved views.
