# Короткая пользовательская проба установщика 0.1.0-alpha.12

Для alpha.12 предлагается короткая проверка поставки. В изолированной Windows
установите EXE и запустите FreeCAD 1.1.4 через ярлык. Убедитесь, что доступен
включённый флажок «Продолжать выполнение» у Line, а Wire позволяет выбрать
«Дуга» и сохранить в одном объекте прямой и круговой сегменты.

Принятые проверки Line и Wire в исходниках и ручная приёмка установщика
alpha.11 сохраняют свой объём. Сценарии удаления ниже служат справочным
перечнем для самостоятельных проверок.

Для обновления деинсталлятора установите текущую версию поверх прежней в тот
же Mod. Целевая проба исправления удаления выполняется в отдельной учётной записи
Windows или в VM с FreeCAD 1.1.4 и новым Mod, где нет прежних копий дополнений.

1. Установите оба компонента. В тестовом Mod временно переименуйте файл
   `UniStation\.managed-by-unistation.ini` и запустите удаление обоих компонентов.
2. Должно появиться сообщение об ошибке обработки UniStation. Проверьте, что
   обе папки остались в Mod, для AxisFlow в журнале нет отметки `Processed`,
   запись удаления сохранилась, а мастер не показал экран успешного удаления.
3. Верните файлу исходное имя и повторите удаление. Оба компонента должны
   удалиться из Mod, а папка копий — автоматически отправиться в Корзину.
   Отдельного вопроса о копиях или сообщения об их успешном удалении быть
   не должно. Проверьте снятие ярлыков и записи удаления.

## Служебная папка после удаления

1. В тестовой Windows установите оба компонента. Добавьте контрольный файл
   в установленную папку UniStation и положите второй контрольный файл
   в другое дополнение в том же Mod.
2. Удалите только UniStation. AxisFlow, `.UniStation-Installer` и запись
   для удаления должны остаться. Затем удалите оставшийся AxisFlow. Проверьте
   отсутствие `.UniStation-Installer` внутри Mod и `UniStation-Backup-…` рядом
   с Mod, наличие копии с первым контрольным файлом в Корзине и сохранность
   второго контрольного файла в другом дополнении.
3. В отдельной пробной установке временно запретите создание папок рядом с
   Mod, оставив сам Mod доступным для записи. После ошибки переноса проверьте
   сохранность `.UniStation-Installer` и записи удаления. Восстановите доступ
   и повторите удаление. Мастер должен завершить перенос без выбора компонентов.
4. Для отдельной чистой установки на локальном диске проверьте, что оба
   компонента уже отмечены по умолчанию. Повторите полное удаление в тихом
   режиме `/S`: папка также должна попасть в Корзину без окон очистки.
5. В отдельной пробной среде заблокируйте файл внутри служебной папки от
   удаления. Если Windows не завершила очистку, мастер должен показать путь
   к оставшейся папке, а не сообщить об успешном удалении копий.

## Обычная установка и удаление

1. Под рабочей учётной записью Windows закройте FreeCAD и запустите
   `UniStation-0.1.0-alpha.12-win64-setup.exe`. В Проводнике у EXE должна быть
   синяя плитка UniStation со стрелкой загрузки при размере значка от 32 пикселей.
   В мелком размере используется синяя плитка без стрелки.
   Проверьте найденный `FreeCAD.exe`, версию и имя пользователя.
   «Обзор» позволяет выбрать другую установку, «Проверить» обновляет результат.
   Проверьте выбор языка и компонентов, путь по умолчанию
   `%APPDATA%\FreeCAD\v1-1\Mod`. При другом профиле выберите его настоящий Mod.
2. Для первой пробы оставьте UniStation, AxisFlow и ярлыки. Завершите установку.
   Если раньше были выбранные компоненты, их папки должны оказаться в
   `.UniStation-Installer\transactions\install-...` внутри выбранного Mod.
3. Проверьте синюю плитку на ярлыке «UniStation - FreeCAD» в меню «Пуск → Все приложения»
   и на рабочем столе, а также значок записи UniStation в «Панели управления →
   Программы и компоненты». Из ярлыка должен запуститься выбранный FreeCAD
   с уже активным UniStation. В списке верстаков у UniStation должен быть
   прозрачный контур. Проверьте его на светлой и тёмной теме.
   Создайте
   небольшой Line через AxisFlow. Убедитесь, что прежние настройки профиля
   доступны. Завершите команду, закройте FreeCAD.
4. Отдельно, когда удобно, проверьте удаление через список приложений Windows:
   выбор компонентов, восстановление прежних папок, сохранение других дополнений
   и настроек. После полного удаления мастер автоматически отправляет копии в Корзину;
   успешная работа в FreeCAD сама по себе не подтверждает удаление/восстановление.

Дополнительные варианты по необходимости: установка только AxisFlow, либо
UniStation без замены уже установленного совместимого AxisFlow, другой каталог.
Для отсутствующего FreeCAD в отдельной пробной среде проверьте вопрос о ручном
выборе: «Да» оставляет выбор файла, «Нет» завершает мастер до установки.
Указание неправильного EXE, версии вне 1.1.1–1.1.4, x86 или сборки без Python 3.11
должно блокировать продолжение. Нельзя считать наличие python311.dll полной
проверкой ABI. Для принудительного ручного выбора можно запустить мастер с
`/FREECAD="C:\missing\FreeCAD.exe"` — другой путь автоматически не подставляется.
В тихом режиме `/S` нужен найденный совместимый FreeCAD либо явный `/FREECAD=...`;
ошибка возвращает код 2 до изменения компонентов.
Проверьте запуск ярлыка под другой учётной записью: объяснение необходимости
собственной установки, без запуска FreeCAD. Проверки чужой учётной записи,
отсутствующей установки и неподдерживаемых версий лучше выполнять в отдельной VM.
После удаления только UniStation его оба ярлыка должны исчезнуть, AxisFlow остаётся.
Не требуется повторять уже подтверждённую работу верстака alpha.4 в FreeCAD 1.1.3.
Не нужно повторять все команды/привязки/атрибуты старых приёмок.

Сообщите кратко: этап, выбранные компоненты/каталог, успех или текст ошибки.
При ошибке установки подходящий журнал — `journal.ini` в каталоге транзакции.
Личные документы и полный профиль прикладывать не требуется.
