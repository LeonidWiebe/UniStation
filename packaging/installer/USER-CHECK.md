# Короткая пользовательская проба установщика 0.1.0-alpha.3

Новая проверка относится к мастеру установки/удаления, а не к повтору всех
прежних приёмок UniStation. Codex `.exe` и FreeCAD не запускал.

1. Закройте FreeCAD. Запустите `UniStation-0.1.0-alpha.3-win64-setup.exe`.
   Проверьте выбор языка и компонентов, путь по умолчанию
   `%APPDATA%\FreeCAD\v1-1\Mod`. При другом профиле выберите его настоящий Mod.
2. Для первой пробы оставьте UniStation и AxisFlow. Завершите установку.
   Если раньше были выбранные компоненты, их папки должны оказаться в
   `.UniStation-Installer\transactions\install-...` внутри выбранного Mod.
3. Запустите FreeCAD привычным способом, выберите UniStation и создайте
   небольшой Line через AxisFlow. Убедитесь, что прежние настройки профиля
   доступны. Завершите команду, закройте FreeCAD.
4. Отдельно, когда удобно, проверьте удаление через список приложений Windows:
   выбор компонентов, восстановление прежних папок, сохранение других дополнений
   и настроек. После удаления убранные версии остаются в служебной папке;
   успешная работа в FreeCAD сама по себе не подтверждает удаление/восстановление.

Дополнительные варианты по необходимости: установка только AxisFlow, либо
UniStation без замены уже установленного совместимого AxisFlow, другой каталог.
Не нужно повторять все команды/привязки/атрибуты старых приёмок.

Сообщите кратко: этап, выбранные компоненты/каталог, успех или текст ошибки.
При ошибке установки подходящий журнал — `journal.ini` в каталоге транзакции.
Личные документы и полный профиль прикладывать не требуется.
