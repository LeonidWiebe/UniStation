# Alpha.12 installation

Use the [installer guide](../docs/installer.md) and
[short package check](installer/USER-CHECK.md). FreeCAD is installed separately. Default Mod:
`%APPDATA%\FreeCAD\v1-1\Mod`. The alpha.11 installer and Line/Wire feature
checks retain their earlier acceptance scopes; the new alpha.12 EXE's own
installation/installed-feature smoke is pending.
